# Boston Housing XGBoost | Streamlit Demo

Educational prediction demo built from the historic Boston Housing dataset. MEDV is in USD thousands, **not a modern home valuation**. Some socioeconomic predictors are unsuitable for real-world property decisions.

## Reproducible environment

Trained using Python 3.13. For consistent joblib model loading, use the same Python major/minor and the pinned `requirements.txt` generated from the training environment.

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The trained `boston_housing_model_v1_0.joblib` and `model_metadata.json` must be generated by this notebook and committed with the app. Do not load untrusted joblib files.

## Deployment

Push the generated deployment folder to a GitHub repository. At https://share.streamlit.io, create an app with the `main` branch and `app.py` as entry point; in Advanced settings select Python 3.13 if available. The notebook contains an explicit, opt-in GitHub publishing cell.

## Evaluation

Metrics are calculated on one held-out test split and are not guaranteed performance in real-world housing markets.
